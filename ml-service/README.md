# ML Service

Python-based machine learning service for the Healthcare Document Intelligence System.

## Responsibilities

The ML service will eventually handle:

- OCR
- Text preprocessing
- Document classification
- Medical Named Entity Recognition (NER)
- Structured information extraction
- ML inference

## Technology

- Python
- FastAPI
- Hugging Face Transformers
- PyTorch
- OCR libraries

## Current Status

Phase 0 — Project Architecture & Setup

Currently, the service contains a minimal FastAPI application with a health-check endpoint.
